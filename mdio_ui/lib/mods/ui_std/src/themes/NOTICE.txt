# 主题素材的来源与许可

本目录的皮肤**不是**凭空写的：`github.css` / `mdmdt.css` / `macos27.css` / `bloom.css` 由生成器从 `vendor/` 里的上游文件机械转换而来
（`scripts/port-theme-github.mjs` / `port-theme-mdmdt.mjs` / `port-theme-hostcss.mjs` / `gen-theme-fonts.mjs`）。
`atelier.css` 是**本仓库原创**（「手作纸」，取法自近三年三类高质量 md 样式，非移植）；
`parchment.css` 也是自有皮肤。改皮肤请改生成器或 vendor 上游，再重跑生成器；不要手改生成物。

## 已知裁剪（转换时主动丢弃的内容）

- GitHub：GitHub 网页专属 DOM（`.octicon` 锚点图标、`.markdown-alert`、`.highlight`、表单控件重置、task-list 专用类）；
  印刷/暗色偏好由容器状态接管（不再用 `@media (prefers-color-scheme)`）。
- Mdmdt：Typora 编辑器外壳（侧栏/文件树/大纲/CodeMirror/megamenu/通知/搜索/窗口 chrome，约 2/3 规则）、
  全部 `@media`（响应式与打印）、标题折叠角标与链接外链图标、`.md-toc`/`.md-htmlblock`/`.md-math` 容器样式；
  调色板变量统一改名 `--mdt-*`；暗色只输出与亮色**不同**的声明（不是第二份 68 KB）。

## 两处与上游行为的差异（有意为之）

1. Mdmdt 的 `--monospace`（JetBrains Mono 栈）在上游**声明了但 0 次使用**，代码块实际没有 mono 栈；
   这里显式给 `code/pre/.md-codeblock` 补 `var(--mdt-mono)`（自托管 JBMono）。
2. std 会把每个节再包一层 `.mdio-std`（floor 里 15px）；两份移植皮肤都补了
   `[data-md-theme="…"] .mdio-doc .mdio-std { font-size: 16px }`，让上游的 em 级联按 16px 基准生效。
